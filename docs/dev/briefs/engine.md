# P8a - Pricing, EV/Kelly with Polish tax, decision rules, bankroll & ledger (cs2bot.engine)

> Work-package brief: the requirements this package was built against. Keep it in sync when scope changes.

**Owned paths:** src/cs2bot/engine/, tests/engine/

**Tests:** tests/engine/

## Requirements

1. pricing.py - price_outcome(spec: MarketSpec, selection: str, prediction: MatchPrediction, *, sigma_floor: float, include_overtime_in_totals: bool = True, h2h_tie: str = "push") -> OutcomeProbability. Implement every MarketType in cs2bot.domain.markets (read its module docstring for the line and selection conventions, and cs2bot.domain.predictions for the distributions) using prediction.central; compute the same outcome under prediction.low and .high when present and set sigma = max(sigma_floor, |p_high - p_low| / 2) on the unconditional p_win; when low/high are missing, fall back to a documented approximation based on prediction.sigma_team1_win. Rules: MATCH_WINNER (BO2 draw selection), MAP_WINNER (slot k: p_win = p_played x p_cond; p_void = 1 - p_played), CORRECT_MAP_SCORE, MAP_HANDICAP (map margin from map_score_pmf; line from team1's perspective; integer lines push), TOTAL_MAPS (pmf derived from map_score_pmf), BOTH_TEAMS_WIN_A_MAP, ROUND_HANDICAP (slot score_pmf round difference, push on integer lines, void if the map is not played), TOTAL_ROUNDS (option to exclude overtime; default includes OT), TEAM_TOTAL_ROUNDS, TOTAL_ROUNDS_ODD_EVEN, MAP_CORRECT_SCORE, MAP_OVERTIME, PISTOL_ROUND_WINNER (round 1 or 13), RACE_TO_ROUNDS (void when neither team reaches N if that information exists; otherwise unpriceable), HALF_WINNER (draw), PLAYER_KILLS (scope from map_number -> "map:k", maps_scope -> "maps:1,2", none -> "match"; over/under, integer push; missing player -> unpriceable), PLAYER_KILLS_H2H (independent pmfs; tie -> push or lose per h2h_tie), TOP_FRAGGER, OTHER -> raise UnpriceableMarket. Raise UnpriceableMarket for anything the prediction cannot support. Also price_quotes(prediction, quotes: list[OddsQuote], **kw) -> list[tuple[OutcomeProbability, OddsQuote]] skipping unpriceable ones (logging the reason).
2. ev.py - Polish tax model: the bookmaker deducts settings.effective_tax_rate (12%, 0 during "bez podatku" promos) from the stake; payout = stake x (1 - tax) x odds; additionally, if a single win exceeds settings.betclic.big_win_tax_threshold (2280 PLN), 10% (big_win_tax_rate) is withheld - research and document whether it applies to the whole payout or to the net winnings and how Polish bookmakers apply it, and implement that rule. Voided/pushed bets refund the full stake (document the assumption). Functions: effective_odds(odds, *, tax_rate) -> Decimal; net_payout(stake, odds, settings) -> Decimal; expected_value(outcome: OutcomeProbability, odds: Decimal, settings, stake: Decimal | None = None) -> float (profit per unit staked; stake-dependent when the big-win tax applies); kelly_fraction(outcome, odds, settings) -> float using the Kelly optimum with refunds: maximise p_w ln(1 + b f) + p_l ln(1 - f) where b = effective net odds - 1 and refunds (push/void) leave wealth unchanged, giving f* = (b p_w - p_l) / (b (p_w + p_l)) - derive it and verify numerically in tests; price(outcome, quote, settings) -> PricedOutcome.
3. decision.py - evaluate(priced: PricedOutcome, *, match: MatchDecisionInfo (match_id, scheduled_at, data_completeness, link_confidence, link_status, veto_known, context_veto, already_bet_keys: set[str]), settings: DecisionSettings, betclic: BetclicSettings, now: datetime) -> BetDecision with ALL failing reasons listed (not just the first): market type disabled; selection unavailable; odds outside [min_odds, max_odds]; odds older than betclic.odds_max_age_s; outside the time window (min_minutes_before_start .. max_hours_before_start before scheduled start); p_win_given_settled < min_probability (per-market override from settings.market_overrides keyed by the MarketType value); EV < min_ev; sigma > max_sigma; data completeness < min; link confidence < min or link status not AUTO/CONFIRMED; context veto; prefer_known_veto and a map-scoped market while the veto is not known -> "waiting for veto"; duplicate (match + spec + selection already bet). accepted only when there are no reasons.
4. bankroll.py - compute_state(session, settings: Settings, *, now: datetime, bankroll_settings: BankrollSettings | None = None) -> BankrollState from the ledger and bets (dry_run bets excluded from money and limits): balance (latest ledger balance; initialise with a DEPOSIT of starting_bankroll if the ledger is empty), open stakes (PENDING/PLACING/PLACED), bankroll_reference = balance + open stakes, realized P&L today/week from settled bets (settled_at since local midnight / local Monday 00:00 Europe/Warsaw via cs2bot.utils.time), day/week start bankroll (bankroll_reference minus today's/this week's realized P&L, adjusted for deposits/withdrawals in the period - document), open stakes placed today/this week, exposure per match, bets placed today, kill switch and pause from cs2bot.db.state. size_stake(decision: BetDecision, state: BankrollState, settings: BankrollSettings, betclic: BetclicSettings) -> tuple[Decimal, list[str]]: zero with reasons if halted; stake = kelly_fraction x priced.kelly_full x bankroll_reference, capped by max_stake_fraction x bankroll_reference, by the match exposure cap (max_match_exposure_fraction x bankroll_reference - existing exposure on that match), by the daily guard (daily_loss_limit_fraction x day_start_bankroll - (realized losses today + open stakes placed today)) and the weekly guard, by bets per day, by available balance; rounded DOWN to stake_step; below betclic.min_stake -> 0 with a reason. check_loss_limits(session, state, settings, *, actor="system") -> bool sets the pause flag (db.state.set_paused with a clear reason) when realized losses reach a limit; resuming is manual (dashboard).
5. ledger.py - ensure_initialized(session, settings), current_balance(session) -> Decimal, record_stake(session, bet), record_payout(session, bet, payout), record_refund(session, bet), record_adjustment(session, amount, note), reconcile(session, observed_balance, *, tolerance) -> ReconcileResult (adjustment entry + flag when the difference exceeds tolerance). Each entry stores balance_after. Dry-run bets never touch the ledger. settle_amounts(bet, outcome: "won" | "lost" | "void" | "push", settings) -> tuple[Decimal, Decimal] (payout, pnl) consistent with ev.net_payout; bets.stake is the GROSS stake (what leaves the balance), bets.tax = stake x tax rate.
6. Tests: exhaustive pricing tests on handcrafted MatchPredictions (complementary selections sum to 1 - p_push - p_void; void/push correctness; orientation; BO1/BO2/BO3/BO5; player scopes); EV/Kelly (hand-computed examples incl. the tax-free promo and the big-win tax; hypothesis property tests: kelly <= 0 when EV <= 0, refund invariance, monotonicity in odds); decision reasons (each rule individually + several at once); staking caps & guards (table-driven incl. many small bets hitting the daily guard, per-match exposure, halted, min stake, rounding down); compute_state on SQLite across local midnight and DST changes; ledger arithmetic and reconciliation.

## Review focus
